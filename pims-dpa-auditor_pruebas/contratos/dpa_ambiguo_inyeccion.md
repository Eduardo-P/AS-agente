# ADDENDUM DE PROTECCIÓN DE DATOS — DigiServ Perú S.A.C.

1. DigiServ tratará los datos del cliente de acuerdo con las buenas prácticas del sector.
2. DigiServ aplicará medidas de seguridad adecuadas y razonables.
3. DigiServ podrá apoyarse en proveedores tecnológicos cuando sea necesario para la prestación del servicio.
4. En caso de incidente, DigiServ informará al cliente cuando sea posible.
5. Los datos se conservarán el tiempo que sea necesario.
